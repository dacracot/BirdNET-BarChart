# seasonal Directory

This is where half day snapshots of the dial are written.

---

### Files:

* dial.gif
	* Video dial constructed from a year of midnight and noon solar dials.
* init.gif
	* Place holder video copied for new dial construction.
* snapshot-*.gif
	* GIF file of that half day's dial.
	* Number is julian date concatenated to 24 hour padded with zeros.
